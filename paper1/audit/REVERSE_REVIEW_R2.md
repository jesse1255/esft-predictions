## 1. Hessian 下界：固定電荷與規範場消去順序

### 1.1 設定

物質場為 n（程式中是共轉的 v），規範場為空間分量 A，Noether 荷 N 固定：

```
E_N[n, A] = E_s[n, A] + N² / (2 I[n]),
I[n] = min_{β→1} F[β; n],   F = ∫ ( β² K[n] + |∇β|²/e² ),
K[n] = f²(1 − n₃²) + g⁻² |∇n₃|².
```

I 只依賴 n：K 由規範不變量 n₃ 構成。`nonaxisym.py` 用的二次型是下列泛函的 Hessian：

```
E_loc[n, A] = E_s[n, A] − (ω₀²/2) ∫ β₀² K[n],     ω₀ = N/I₀,
```

β₀、I₀ 是背景的極小子與極小值。E_loc 與 E_N 在背景處的值和一階導數都相同。

### 1.2 命題 1（固定電荷項）

對任何擾動 (δn, δA)：

```
δ²E_N = δ²E_loc + (N²/I₀³)(δI)² + (N²/2I₀²) · Rᵀ (∂²_β F)⁻¹ R   ≥   δ²E_loc,
δI = ∫ β₀² δK,     R = ∂_β(∂_n F · δn) = 2 β₀ δK   （β 空間上的線性泛函）。
```

**證明。** β*(n) 滿足 ∂_βF(β*; n) = 0。包絡定理給出 I′ = ∂_nF。再微分一次，並用 dβ*/dn = −(∂²_βF)⁻¹ ∂_β∂_nF：

```
I″ = ∂²_n F − Rᵀ (∂²_β F)⁻¹ R,     ∂²_n F(δn, δn) = ∫ β₀² δ²K.
```

代入 δ²(N²/2I) = −(N²/2I²) I″ + (N²/I³)(I′)²，其中第一項的 ∂²_nF 部分正是 E_loc 的電荷項。∂²_βF = 2(K − e⁻²∇²) 在 β − 1 → 0 的函數上正定（K ≥ 0），所以兩個多出的項都 ≥ 0。∎

離散版本完全相同：I_h 是有限元素空間上的極小，A_ff 正定。所以這一步在離散系統中是**精確**的，不只是連續極限的陳述。

**k ≥ 1 的扇區。** δK ∝ cos kφ 或 sin kφ，對 φ 積分為零，因此 δI = 0。只剩響應項（β 的 k 模響應），它是 Gram 形式，半正定。

### 1.3 命題 2（規範場的消去順序不影響結論）

把 Hessian 按物質（m）與規範場（A）分塊，H_true = H_loc + diag(P, 0)，P ⪰ 0。兩者的 H_AA 相同，而且正定：規範固定後的 Maxwell 項加上 e²M。

- Schur 補：S_true = S_loc + P ⪰ S_loc。在同一個質量矩陣 M_mm 下，Courant–Fischer 給出每一個特徵值 λ_j(S_true) ≥ λ_j(S_loc)。
- 全矩陣：Haynsworth 慣性可加性 In(H) = In(H_AA) + In(S)，所以 #neg(H_true) = #neg(S_true) ≤ #neg(S_loc) = #neg(H_loc)。

其實不需要分塊結構。只要 H_true ⪰ H_loc 作為全空間的二次型成立，就有 min_y H_true(x, y) ≥ min_y H_loc(x, y)。所以「先放鬆 A 再看物質」與「直接看全 Hessian」給出同樣的結論。∎

### 1.4 規範固定項

程式對 E_s + (κ/2)∫(∇·A)² 取 Hessian。在駐定點，純規範方向 g_χ = (eχ e₃ × n, ∇χ) 是 H_s 的零向量。任何擾動都可寫成 w = v + g_χ，其中 ∇·δA_v = 0：解 Δχ = ∇·δA，並用背景滿足 ∇·A₀ = 0（背景是規範固定能量的極小）。於是

```
H_gf(w, w) = H_s(v, v) + κ ‖Δχ‖².
```

所以規範固定後的負方向，恰好就是 H_s 在 Coulomb 切片上的負方向；規範零模被抬高，但不會製造或藏起負模。

在格點上，只有常數 χ（整體相位）是精確對稱，其餘規範方向只是近零。這一點的誤差屬於離散誤差，數值上相位零模是 −1.8×10⁻¹⁰（e = 0.3），其他規範方向被 κ 項抬到正值。

## 2. k ≥ 5 的扇區與費米子參數點

### 2.1 H(k) 對 k 是精確的二次多項式

k ≥ 1 時，第 k 扇區的二階變分在一個與 k 無關的係數空間上是 k 的二次多項式：

```
H(k) = A + k B + k² C.
```

理由有三：
- 背景與 φ 無關；
- k 只經由 ∂_φ 進入（∂_φ 把 cos kφ 係數換成 k 倍的 sin kφ 係數，反之亦然）；
- φ 積分用 2k + 3 個等距點，對次數 ≤ 2k 的三角多項式是精確的。

k ≥ 2 時軸上的條件（全部為零）也與 k 無關，所以 A、B、C 可由 H(2)、H(3)、H(4) 精確解出。直接組裝 H(5) 核對：相對差 3×10⁻¹²（(e, N) = (0.3, 1)）與 1.3×10⁻¹⁵（(0.6, ½)），只是捨入誤差。程式：`charged_mode/run_kbound.py`。

### 2.2 k = 5…60 逐一檢查

H_AA 正定，所以由 Haynsworth 可加性，H(k) 的負特徵值個數就等於規範放鬆後 Schur 補的負特徵值個數。對每個整數 k 取 LDLᵀ 慣性指數（PARDISO，每個 k 約 4 秒）：

| 參數點 (e, N) | k = 2, 3, 4 | k = 5…60 | 擾動主元 | C 的慣性 |
|---|---|---|---|---|
| (0.3, 1) | 0, 0, 0 | 全部 0 | 0 | (80 010, 0, 0)，正定 |
| (0.6, ½) | 0, 0, 0 | 全部 0 | 0 | (80 010, 0, 0)，正定 |

**對照組**（確認方法看得到連續譜）：以物質 L² 質量 M 平移，H(4) − σM 的負特徵值個數在 σ = 0.99、0.9995 時為 0，在 σ = 1.0005 時為 12，在 σ = 1.01 時為 50。兩個參數點相同。所以慣性指數確實能分辨出連續譜的起點。

### 2.3 尾部：一次檢查就蓋住所有 k ≥ 20

```
H(k) − H(k₀) = (k − k₀) [ B + (k + k₀) C ].
```

若 B + 2k₀C ⪰ 0，因為 C ⪰ 0，對所有 k ≥ k₀ 就有 H(k) ⪰ H(k₀)。

- B + 2k₀C 的負特徵值個數：k₀ = 10 時為 106（(0.3, 1)）與 24（(0.6, ½)）；k₀ = 20、40、60 時都是 0。
- 所以兩個參數點都有 H(k) ⪰ H(20) ≻ 0 對所有 k ≥ 20 成立。
- 加上 k = 5…19 的逐一檢查，**離散模型（ne = 32）中所有 k ≥ 5 的扇區都沒有負模**。這是一個封閉的證明，不是外推。

k₀ = 10 不通過，是因為 B 中與 k 線性的交叉項（ΦT·q 等）要到 k ≳ 10–20 才被離心項 k²C 壓住。這也說明為什麼 5 ≤ k < 20 必須逐一檢查。

**解析估計能走到哪裡。**
- **離散模型：** 上面的尾部不等式本身就是嚴格估計。它只用到 H(k) 對 k 的代數結構與 C ⪰ 0，把「所有 k ≥ 5」化成 k = 5…19 的有限個檢查加上一個 k₀ = 20 的檢查。
- **連續極限（圖像，非證明）：** H(k)/k² → C ≻ 0，高 k 的擾動被離心位壘 ∝ k²/ρ² 推離核心。要把它寫成有明確 k_c 的估計，得用 C 控制 B。困難在於 B 含有擾動的一階導數（Skyrme 項的交叉項，形如 (k/ρ)·背景·δv·∂δv），所以 −B 不能只被 C 控制。用 Cauchy–Schwarz 可以把 kB 拆成「½ × 梯度項」加「k² × 背景加權質量項 W」，於是只要逐點有 C 嚴格大於 2W，而且 A 的非梯度部分的負值也被 C 控制，大 k 就沒有負模。這個逐點比較要用背景的振幅，本輪沒有做。所以連續極限中的 k ≥ 5 目前只由 ne = 32 的離散封閉支持。

## 3. M2′：泛函、拓樸荷、正下界、κ₃ ≈ 0.92 兩側

### 3.1 完整能量泛函

連續形式（U = [Z₁ Z₂ Z₃] ∈ U(3)，模掉右乘對角相位）：

```
E[U] = ∫ d³x [ Σ_{a<b} r_ab |ω_i^{ab}|²
               + (κ/2)  Σ_{i<j} Σ_a (F^{(a)}_{ij})²
               + (κ₃/2) Σ_{i<j} Σ_{a≠c} |C^{ac}_{ij}|²
               + Σ_a m_a² (1 − |Z_aa|²) ],
ω = U†∂U,
F^{(a)}_{ij} = 2 Im Σ_{b≠a} ω̄_i^{ba} ω_j^{ba}   ( = −i Tr P_a[∂_iP_a, ∂_jP_a] ),
C^{ac}_{ij} = ω_i^{ab} ω_j^{bc} − ω_j^{ab} ω_i^{bc}     ({a, b, c} = {1, 2, 3}).
```

κ₃ = κ 時，兩個四階項合起來等於 (κ/2)Σ_{i<j}‖[ω_i^off, ω_j^off]‖²。本輪的數值取 r_ab = 2（λ = 1，S₃ 對稱點）、κ = 2、m_a² = 1。

**離散形式**（`flag_axisym.py`）：
- U 放在 Q2 有限元素節點上，在求積點以 U_q = Σ_i φ_i(x_q) U_i 內插。U_q 不嚴格么正。
- 軸對稱：U = R_L(φ)Û(ρ, z)，ω_φ = Û†(iL)Û/ρ。
- ω_q = U_q† ∂U_q，把上式的積分換成求積和。
- 節點上以 Cayley 映射 U = U₀·Cay(X) 參數化，X 只有非對角元，對角相位是規範。

### 3.2 拓樸荷

**連續定義。** 取在無窮遠趨於 I 的提升 Ũ = R_L Û R_L⁻¹。Hopf 度數是 π₃(SU(3)) 的度數：

```
Q = (1/24π²) ∫ Tr(ω̃ ∧ ω̃ ∧ ω̃),     ω̃ = Ũ⁻¹dŨ = R_L (ω − iL dφ) R_L⁻¹,
Tr ω̃³ = 3 Tr( ω_ρ [ω̃_φ, ω_z] ) d³x      ((ρ̂, φ̂, ẑ) 右手系)。
```

用 Maurer–Cartan 方程把 ω 分成對角聯絡 a 與非對角部分 β，可得

```
Q = Q_CS + Q_3,
Q_CS = −(1/8π²) Σ_a ∫ a_a ∧ da_a,     da_a = −(β∧β)_{aa} ∝ F^{(a)},
Q_3  = (1/24π²) ∫ Tr(β ∧ β ∧ β),      Tr β³ = Σ_{a≠c} β^{ca} ∧ (β∧β)^{ac},   (β∧β)^{ac}_{ij} = C^{ac}_{ij}.
```

兩部分各自在規範變換 U → U·diag(e^{iχ_a}) 下不變：三循環的相位互相抵消。

**離散定義。** 用內插的 U_q 在求積點直接計算上式。U_q 不嚴格么正，所以 Q_h 不是整數，隨加密趨於整數：嵌入態 Q_h = −0.99936（ne = 16）、−0.99988（ne = 24）、−0.99996（ne = 32；盒 a = 2.5、4 時為 −0.99998、−0.99989）。所謂「荷守恆」在數值上指 |Q_h − Q_h(起點)| 停在離散誤差的量級。

### 3.3 M2 的精確措辭（更正上一輪）

能量是非負的，所以上一輪「沒有拓樸能量下界」的寫法不精確。應改為：

> **M2 沒有正的拓樸下界：Q = 4 扇區的能量下確界是 0，而且取不到。**

證明不變：實旗 U ∈ SO(3) 使所有 F^{(a)} ≡ 0，而 SO(3) ⊂ SU(3)（自旋 1）的 Dynkin 指標是 4，所以這類構型的度數是 4k。對 Q = 4 的實構型縮放，E(R) = R E₂ + R³ E_pot → 0。

Q = 1 在 M2 中是否也沒有正下界，**沒有證明**。上一輪也已撤回「ne = 16 的荷流失是證據」：κ₃ > 0 時同樣會流失。流失的機制見 §3.6(a)。

### 3.4 M2′ 的正下界（證明，含明確常數）

記號：r_min = min r_ab > 0，κ = min κ_a > 0，κ₃ > 0。‖β‖₂² = Σ_{a≠b}∫|β^{ab}|²，‖C‖₂² = Σ_{i<j}Σ_{a≠c}∫|C^{ac}_{ij}|²，2-形式的範數取 Σ_{i<j}。

```
E₂ = ∫ Σ_{a<b} r_ab |ω^{ab}|² ≥ (r_min/2) ‖β‖₂²,   E_K = Σ_a (κ_a/2) ‖F^{(a)}‖₂²,   E_C = (κ₃/2) ‖C‖₂².
```

取一個在無窮遠趨於 1 的整體提升 Ũ（S³ 上的 T² 叢是平凡的，所以提升存在），它的對角聯絡 a_a 滿足 da_a = −(β∧β)_{aa} = iF^{(a)}。

1. **Chern–Simons 部分。** 對角規範變換可以把每個 a_a 放進 Coulomb 規範，這不改變 Q。Coulomb 規範下 ‖∇a_a‖₂ = ‖da_a‖₂，所以由最佳 Sobolev 常數（Aubin–Talenti）與 Kato 不等式，

   ‖a_a‖₆ ≤ S₃ ‖F^{(a)}‖₂，    S₃ = 3^{−1/2}(2/π)^{2/3} = 0.42726。

   Hölder 內插給出 ‖F‖_{6/5} ≤ ‖F‖₁^{2/3}‖F‖₂^{1/3}，所以 |∫a_a∧da_a| ≤ S₃‖F^{(a)}‖₂^{4/3}‖F^{(a)}‖₁^{2/3}。

   逐點有 |F^{(a)}| ≤ Σ_{b≠a}|ω^{ba}|²：把 ω^{ba} 寫成 x + iy，F^{(a)} 的每一項是 2x∧y，而 |2x∧y| ≤ |x|² + |y|²。因此 ‖F^{(a)}‖₁ ≤ E₂/r_min；另外 ‖F^{(a)}‖₂² ≤ 2E_K/κ。用 E_K E₂ ≤ E²/4，

   |Q_CS| ≤ (1/8π²) Σ_a |∫a_a∧da_a| ≤ C₁ E^{4/3}，    C₁ = 3S₃ / [8π² (2κ r_min)^{2/3}]。

   這就是 Vakulenko–Kapitanski 的論證，只是把常數寫出來。
2. **三循環部分。** 由 Tr β³ = Σ_{i 循環} Σ_{a≠b} β_i^{ab} C^{ba}_{jk}（數值程式裡的 3 Tr ω_ρ[ω_φ, ω_z] 就是這個式子）與 Cauchy–Schwarz，逐點 |Tr β³| ≤ |β||C|。所以

   |Q_3| ≤ (1/24π²)‖β‖₂‖C‖₂ ≤ (1/24π²)·√(2E₂/r_min)·√(2E_C/κ₃) ≤ C₂ E，    C₂ = 1 / [24π² √(r_min κ₃)]。
3. **結論。** |Q| ≤ C₁E^{4/3} + C₂E。左邊固定、右邊對 E 遞增，所以 E ≥ E*(|Q|)，E* 是 C₁E^{4/3} + C₂E = |Q| 的根，Q ≠ 0 時嚴格為正。

**數值（`audit/m2prime_bound.py`）。** r_ab = κ = 2（λ = 1）：C₁ = 4.06×10⁻³。

數值上的 Q = 1 嵌入解能量是 321.6，所以這個下界弱了約 5.7 倍，但它是**明確、嚴格、正的**。κ₃ → 0 時 C₂ ∝ κ₃^{−1/2} → ∞，下界消失，與 M2 的實旗反例一致。

### 3.5 κ₃ 轉變的階：局部正規形

**設定。** S₃ 點（λ = 1），l₃ = 0 扇區（最先失穩的扇區）。κ₃ 降到 κ₃* 時，嵌入孤子在法向區塊失穩。

U(1) = diag(1, 1, e^{iβ}) 固定嵌入解：嵌入解是區塊對角的，第三個分量就是 e₃。在 Cayley 圖上，它把法向座標 x₀₂、x₁₂ 乘上同一個相位，區塊內座標 x₀₁ 不動。這是離散能量的精確對稱。所以臨界特徵空間是一對 {ξ, Jξ}，Jξ 是 ξ 轉 90° 的相位。

**約化能量。** ξ 以 L² 質量 M 正規化，H_C = ∂H/∂κ₃。沿 tξ 加上區塊內的橫向位移 y：

```

a₁ = ξᵀ H_C ξ,   E₄ = d⁴E(tξ)/dt⁴ |₀,   g = D³E[ξ, ξ, ·].

三個對稱事實，都是精確的，數值上也核對過：
1. 奇次項為零：t → −t 是 U(1) 中 β = π 的元素。
2. g 沒有法向分量：D³E[ξ, ξ, y_n] 有三條法向腳，U(1) 荷是奇數，所以恆為零（數值上 max|g_normal| = 0）。法向的橫向響應因此不在 t² 階出現。
3. t⁵ 階的每一項都有奇數條法向腳，也為零。下一個修正是 t⁶。

對 y 取極小，y = −(t²/2)H_b⁻¹g，得

```

## 4. 有限尺寸約束：原稿式 7–17 逐式核算

原稿 `ESFT_FoP_SPRINGER.tex`（git df29386 的 `papers/paper01_foundations/`），式號依編譯順序：
- 式 4、7：F₁(q²) = 1 − q²a²/6；
- 式 8–10：g−2；式 11：由 g−2 定的界；
- 式 12–14：Lamb shift；式 15–16：1S–2S；式 17：Λ_core；
- 第 2.6 節（tex 212–221）與討論（tex 1182–1199）：「LEP 不適用」；
- 討論（tex 1149–1170）：Rydberg 吸收。

程式：`audit/finite_size_constraints.py`，結果在 `finite_size_constraints.json`。

### 4.1 先定物理模型

- **M-e：** 只有電子帶電荷半徑 a；μ 子與質子照舊。
- **M-u：** 所有帶電輕子共用同一個 a。

兩者都假設結構**只**出現在 F₁（電荷形狀因子）。若模型還有自己的磁形狀因子（例如本專案帶電 Hopf 孤子的靜態電流磁矩），它會在樹圖階給出 δa，下面所有 g−2 的界都不適用。

協變寫法（度規 +−−−）：F₁(q²) = 1 + q²⟨r²⟩/6，⟨r²⟩ = a²。原稿的 1 − q²a²/6 是空間型 q² = −|q|² 的寫法。

### 4.2 g−2（式 7–11）

**重推。** 在 Schwinger 圖中，外部光子頂點取 q² → 0 時 F₁ = 1；內部光子的兩端各帶一個 F₁(k²)：

```
F₁(k²)²/k² = 1/k² + ⟨r²⟩/3 + O(k²).
```

常數項是接觸作用。它等於質量 M、耦合 g_V 的向量粒子在 k² ≪ M² 的極限，對應 g_V²/M² = −e²⟨r²⟩/3。向量粒子的一圈貢獻為 a_V = (g_V²/8π²)∫₀¹ 2x²(1−x)dx/[x² + (1−x)M²/m²]，重極限是 g_V²m²/(12π²M²)。數值核對：M/m = 30、100、300 時，M²/m² 乘上積分為 0.6561、0.6652、0.6665，趨於 2/3。所以

```
δa = −(α/9π) m² ⟨r²⟩.
```

- **算子基底。** 電荷半徑算子 (⟨r²⟩/6) ψ̄γ^μψ ∂^νF_{νμ}，經運動方程 ∂^νF_{νμ} = eJ_μ，化為 (e²⟨r²⟩/6)(ēγ^μe)J_μ^em。它對 F₂(0) 的一圈貢獻只來自 Schwinger 拓樸。電子閉圈的拓樸只產生 γ^μ 結構，不貢獻 F₂(0)。
- **與原稿比較。** 原稿式 8 的被積函數 x⁴(1−x)/[x²(1−x)² + x(1−x) + x²] 無法由標準費曼參數化得到。式 10 的係數 αI/(12π)（I = 0.04675）比 α/9π 小 28.5 倍。符號（負）與 (m a)² 標度是對的。
- **界。** a_e 的實驗減理論（LIT，搜尋摘要，arXiv:2504.21179）：用 α(Rb) 為 +4.8(3.0)×10⁻¹³，用 α(Cs) 為 −8.7(3.6)×10⁻¹³。電荷半徑只給負的 δa。
  - 用 α(Rb)：95% 下 a < 7.9×10⁻³ fm。
  - 用 α(Cs)：資料反而「偏好」a = 0.022 fm（範圍到 0.030 fm）。

  但這兩個數都被 4.3 節的 LEP 界排除兩個數量級，所以 g−2 在 M-e／M-u 中不是有效約束。

### 4.3 LEP 的匹配（原稿 tex 212–221、1182–1199）

- **符號。** e⁺e⁻ → μ⁺μ⁻ 的轉移動量是類時的，q² = s > 0，所以 F₁(s) = 1 + s⟨r²⟩/6 > 1。電荷半徑讓 s 通道振幅**增大**，也就是與光子交換**相長干涉**。
- **匹配。** e²F_e(s)F_μ(s)/s = e²/s + e²(⟨r_e²⟩ + ⟨r_μ²⟩)/6 + O(s)。與向量–向量（VV）接觸作用 (g²/Λ²)(ēγe)(μ̄γμ)（g²/4π = 1）比較：
  - M-e：a² = 6/(αΛ²)；
  - M-u：2a² = 6/(αΛ²)。
- **數值。** LIT（搜尋摘要，原表未打開）：LEP e⁺e⁻ → μ⁺μ⁻ 的 VV 模型，95% CL 下相長 Λ⁺ = 21.6 TeV、相消 Λ⁻ = 13.7 TeV。相長這一個才適用，給出
  - **a < 2.6×10⁻⁴ fm（M-e）**；
  - **a < 1.9×10⁻⁴ fm（M-u）**。

  若誤用相消的 13.7 TeV，會得到 4.1×10⁻⁴ fm。上一輪的「3–6×10⁻⁴ fm」只用了 Λ ≈ 10–20 TeV，沒有處理符號，應以此取代。
- **展開是否成立。** √s = 200 GeV 時 √s·a ≈ 0.27，sa²/6 ≈ 0.012，所以一階展開有效。
- **原稿的論證。** 原稿說 q²a² 形狀因子修正與 1/Λ² 接觸作用「參數化上不同」。這是錯的：兩者由運動方程嚴格等價，而且 LEP 在 s 通道直接量到的正是這個 s 依賴。

### 4.4 原子譜：電子半徑與質子半徑簡併（式 12–16，tex 1149–1170）

到最低階，nS 能階的有限尺寸位移是

```
δE_nS = (2/3) α⁴ m_r³ (r_p² + r_e²) / n³ · δ_ℓ0,
```

C_1S = 1.564 MHz/fm²，1S–2S 為 1.368 MHz/fm²。

**原稿的漏洞。** 原稿的「Rydberg 吸收」討論只考慮了 R∞ 的 1/n²。但**質子半徑項與 a² 項的 n 依賴完全相同**（都是 1/n³ δ_ℓ0），所以電子氫只能量到和 s_H = r_p² + r_e²，無論用幾條躍遷都分不開。未算出的高階 QED 項對 S 態的主要部分也是 1/n³，同樣與 s_H 簡併。CODATA 用有相關先驗的加性修正處理它們。

**聯合模型。** 參數為 (R∞, r_p², r_e², r_μ²)。各觀測量：
- 電子氫：決定 R∞ 與 s_H；
- μ 氫：決定 s_μ = r_p² + r_μ²；
- e–p 散射：量到 s_H；
- μ–p 散射：量到 s_μ。

所以：
- **M-u（r_e = r_μ）：** 全部原子與散射資料都只量到 r_p² + a²，**a 完全不受約束**。
- **M-e（r_μ = 0）：** r_e² = s_H − s_μ。電子氫的「只用電子氫」r_p 已經對 R∞ 與理論修正邊際化，直接拿來用就是正確處理共變的方式。

M-e 下的結果（μH：r_p = 0.84060(39) fm，LIT）：

| 電子氫輸入（LIT） | r_p | r_e² (fm²) | 偏離 0 | r_e 的 95% 上限 |
|---|---:|---:|---:|---:|
| CODATA 2022 只用電子 H+D（搜尋摘要：0.8529、相對 5.1×10⁻³、與 μH 差 2.8σ） | 0.8529(44) | +0.0208 ± 0.0075 | 2.8σ | 0.18 fm |
| Beyer 2017（2S–4P + 1S–2S） | 0.8335(95) | −0.012 ± 0.016 | −0.7σ | 0.16 fm |
| Fleurbaey 2018（1S–3S + 1S–2S） | 0.877(13) | +0.063 ± 0.023 | 2.7σ | 0.32 fm |
| Bezginov 2019（2S–2P） | 0.833(10) | −0.013 ± 0.017 | −0.8σ | 0.17 fm |
| Grinin 2020（1S–3S + 1S–2S） | 0.8482(38) | +0.013 ± 0.007 | 2.0σ | 0.15 fm |
| 2S–nS（n = 8, 9, 10）+ 1S–2S，arXiv:2604.26401 | 0.8433(31) | +0.005 ± 0.005 | 0.9σ | 0.12 fm |

- 上限取單邊 95%，並考慮 r_e² ≥ 0 的物理邊界。
- CODATA 2022 只用電子資料的數值取自搜尋摘要。摘要中同時出現「(13)」，與它自己的「相對 51×10⁻⁴」和「差 2.8σ」不符，所以取 (44)。需核對原文。

**結論。**
- M-e 下，原子譜給的上限是 0.12–0.32 fm，取決於輸入。上一輪的「0.16–0.18 fm」是其中兩列，而且是**上限**，不是量到的值。
- 若把 CODATA 只用電子資料與 μH 的 2.8σ 差距解讀為電子半徑，會得到 r_e ≈ 0.14 fm。這個值被 LEP 排除約 500 倍，所以它不可能是 F₁ 型的電子半徑，只能是光譜學或系統誤差問題。
- 原稿式 16 的算術可重現（2.701×10⁻³ fm），但前提錯了。1S–2S 中質子項是 967 kHz；僅 μH 的 r_p 誤差就帶來約 0.9 kHz，是 10 Hz 的 90 倍。何況 1S–2S 本身是 R∞ 的輸入。

## 5. 帶電模型的 FR 條件與電荷量子化（更正上一輪措辭）

上一輪寫「費米子量子化時 J、N 同為半整數，最小電荷 Q = e/2」。任務書指出，「可有半整數自旋」一般推不出「電荷是半個電子電荷」。以下把這個結論在**本模型**中推一次，並說清楚 e/2 的意思。

1. **規範化不改變 π₁。** 規範後的組態空間是 C = {(n, A)}/G₀，G₀ 是在無窮遠為 1 的規範變換。G₀ ≃ Map₀(S³, S¹) 弱可縮（π_k = π_{k+3}(S¹) = 0），並且自由作用在 A 上。所以 C ≃ Map_Q(S³, S²) × (可縮的 A 空間)，π₁(C) ≅ π₁(Map_Q(S³, S²))。
   Q_H = 1 時此群為 ℤ₂，而且 2π 空間轉動是非平凡元素。這兩點取自文獻（Krusch & Speight 2006，hep-th/0503067），本輪未重推。
2. **轉動迴路等於同位轉動迴路。** m = 1 的軸對稱解滿足 n(R_z(α)x) = R₃(α) n(x)，A 軸對稱。所以把組態繞 z 軸轉 α，等於做一個整體 U(1) 變換（常數 χ = −α/e）。在 C 中，2π 空間轉動迴路與（反向的）2π 同位轉動迴路是**同一條迴路**。
3. **FR 相位相同。** 同一條迴路只能有一個 FR 相位，所以 e^{2πiJ} = e^{2πiN}：J 與 N 同為半整數，或同為整數。這是本模型 m = 1 等變性的結果，不是「自旋 ½」本身的推論。
4. **e/2 的意思。** N 以場量子（複場 n₁ + in₂）的荷 e 為單位。N ∈ ℤ + ½ 表示孤子帶**元激發電荷的一半**。若要把這個孤子當成電子（荷 −e_el），就必須 e = 2e_el，也就是模型的基本介子帶 ±2e_el。這是可檢驗的結構性推論，並不等於「電子帶半個電荷」。
5. **前提。** 古典基態是 m = 1 的軸對稱解；選擇費米子 FR 表示。若選玻色子，J 與 N 都是整數。

## 6. 兩篇論文（兩個研究目標）與可重現性

### 6.1 研究目標 A：模型內的結果（可重現，可以寫成一篇或兩篇）

**A1　帶電規範 Hopf 孤子（M1）**
- 作用量與軸對稱全場解：網格 32–96 以 h⁴ 收斂，多初值，virial 殘差。
- 線性穩定：
  - 軸對稱 Hessian；
  - k = 0…4 的非軸對稱譜，以及 k ≥ 5（第 2 節）；
  - 兩個參數點：(e, N) = (0.3, 1) 與費米子點 (0.6, ½)；
  - 固定電荷下界的證明（第 1 節）。
- 半古典量子化：
  - FR 條件在本模型中的推導（第 5 節）：J 與 N 同奇偶，所以 J = ½ 時 N = ½；
  - 磁矩投影 ⟨cos θ⟩ = −1/3；
  - 精確標度 g_static = κ_g(M r_rms)²。
- **負結果：** 在半古典可控區，M·r_rms ≥ 3.0，不能對應電子。

**A2　旗流形 Hopf 孤子**
- M2 的缺陷：Q = 4 扇區的下確界為 0（嚴格）。M2′ 的修補與正下界（證明，常數已算：Q = 1 時 E ≥ 56.5，數值解 321.6）。
- S₃ 點的嵌入孤子：在 M2 中不穩定（λ_c ≈ 2.46），在 M2′ 中穩定（λ_c ≈ 0.05）。
- λ 方向：12 分支與 13/23 分支在 λ = 1 發生由對稱性決定的一級共存；兩側都局部穩定，線性閾值遠離共存點。
- κ₃ 方向：臨界點 κ₃* ≈ 0.92。局部正規形 c₄ > 0，轉變在局部是連續（超臨界）的；R 對稱切片中 κ₃* 下方的 F₂ 極小收斂，振幅隨 δ 連續趨於零，Hopf 荷守恆（第 3.5–3.6 節）。全域圖像要等規範不變的離散化。
- 方法上的教訓：離散嵌入態是鞍點（連續零模被格點抬成負值），必須用精確的離散對稱把它們切掉，才能談「兩側」與荷守恆。

A2 可以當成方法示範：在一個有明確作用量、有拓樸下界的模型裡，怎麼把「一級共存」和「連續分岔」分開。它與 7 月的問題相關，但不依賴 7 月的檔案。

## 7. 反駁這一輪的結論

- **下界的證明**依賴兩件事：固定 N 的能量形式正確，β 問題的邊界條件正確。離散規範不變性只是近似。證明只排除線性負模，不涉及非線性穩定。
- **k ≥ 5 的結論是離散模型（ne = 32）的陳述。** 尾部檢查若通過，對這個離散模型是嚴格的。但連續極限只在 k = 0、1 做過 ne = 48 的核對。
- **費米子點的 k = 1 有一個束縛模（0.9026）。** 它是正的，不影響穩定性，但說明譜的細節依參數而變。其他參數點沒有檢查。
- **M2′ 的正下界**：常數已算，但下界比數值解弱約 5.7 倍，只證明「有正下界」，不能拿來估計孤子質量。正則性假設沒有逐條驗證。數值全在軸對稱擬設內。
- **Landau 係數是局部陳述**，而且只在 l₃ = 0 扇區（最先失穩的扇區）。超臨界分支之後會不會對其他 l₃ 扇區或非軸對稱擾動失穩，沒有檢查。「連續轉變」只在 κ₃* 附近成立；遠處若有能量更低、與嵌入解不相連的 F₂ 態，局部分析看不到。
- **R 對稱切片**把 z 平移、同位轉動與 F₂ 分支的 Goldstone 方向切掉。這在連續極限中是合法的（它們是零模），但切片也會藏起任何真正的 R 奇失穩。本輪的防線是：列出每個端點的 R 奇譜，確認那裡只有這三個方向，而且它們的值隨網格變細而趨於零。若某個 R 奇負值不隨 ne 消失，結論就要重做。
- **大振幅延拓**只在 ne = 16、24 做過，而且受節點相位的格點效應影響；§3.6(d) 的跳躍與遲滯不能當結果引用。我也沒有檢查 T 以外、與嵌入孤子不相連的其他候選態。**第三輪更新：** 已用規範不變離散化在 ne = 16、24、32 重做，跳躍與遲滯是假象（`../charged_mode/FLAG_GAUGE_INVARIANT.md`）；與嵌入孤子不相連的候選態仍未系統搜尋。
- **c₄ 本輪改過一次**（第一版的平移求解高估 1–13%）。修正後各網格與盒尺寸的差異仍有幾 %，所以 c₄ 的數值只到兩位有效數字；結論只依賴它的正負號，而符號也由非線性解獨立確認。
- **有限尺寸約束**用到的 LIT 數值（CODATA 2022 只用電子資料的 r_p、LEP 的 21.6 TeV、a_e 的比較值）都來自搜尋摘要，而且 CODATA 只用電子資料的不確定度有歧義。M-e／M-u 的分析假設結構只出現在 F₁。
- **FR 的論證**中，「Q_H = 1 時 π₁ = ℤ₂、2π 轉動迴路不可縮」取自文獻。規範空間的同倫論證是標準的，但本輪沒有寫出完整的函數分析細節。
