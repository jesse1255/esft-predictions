### 4.3 Holonomy 提案（任務四.4）

- **U ∈ SU(2)：** Tr U = 2cos φ ∈ [−2, 2]，所以 Δ = (Tr U)² − 4 = −4sin²φ ≤ 0 恆成立。只有橢圓型（及 ±1），不存在雙曲型。
- **CP¹ 的自然聯絡：** Hopf 束的 Berry 聯絡與 M1 的規範場 A 都是阿貝爾的，holonomy 只是 U(1) 相位 e^{ie∮A}（Aharonov–Bohm 相）。在 CP¹ 上它作用為恆等，不能做 Möbius 分類。
- **SU(1,1) ≅ SL(2,ℝ)：** 無損傳輸線的 Smith 圖 Möbius 映射屬此類。跡為實數，所以 Δ 的正負有意義：Δ < 0 橢圓、Δ = 0 拋物、Δ > 0 雙曲。
- **SL(2,ℂ)：** 有損的一般情形。Δ 一般為複數，其「正負」沒有意義。必須用 tr² ∈ [0, 4) 判橢圓、tr² = 4 判拋物、tr² ∈ (4, ∞) 判雙曲，其餘為 loxodromic。
- **嚴格對應的版本是 Floquet／Bloch 理論：** 一維週期介質的單胞傳遞矩陣中，|Tr T| < 2 是通帶（傳播，即「開放傳輸」），|Tr T| > 2 是禁帶（衰減），|Tr T| = 2 是帶邊（「臨界」）。**方向與直覺命名相反：** 橢圓型對應開放，雙曲型對應衰減。
- **閉合粒子**是可正規化的束縛態，由整體邊界條件決定，不是局部跡的類別。孤子背景不是週期的，應改用散射資料：Jost 函數、束縛態極點、相移。
- **最小可檢驗版本：** 在 M1 的線性擾動徑向方程（實位勢，傳遞矩陣 ∈ SL(2,ℝ)）上，逐頻率計算跨殼層的傳遞矩陣。先確認 Δ 的符號只是在反映 ω 相對質量隙 μ 的大小，再檢查是否有任何超出標準色散的資訊。

2. J = ½ 為 FR 允許；
3. 轉動能 / M < 10%，半古典近似有效。

**失敗門檻（任一成立）：**
