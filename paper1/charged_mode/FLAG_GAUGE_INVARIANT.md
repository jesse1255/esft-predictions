# 第三輪：旗流形模型的規範不變離散化，與 κ₃ 轉變的全域圖像

## 1. 問題

舊離散化（`FlagModel(disc="u")`）在 Q2 有限元素節點上存 U = [Z₀ Z₁ Z₂]，在求積點內插 U 本身。連續極限中 U → U·diag(e^{iθ_a(x)}) 是規範變換；在網格上，每個節點的相位各自進入內插，所以離散能量依賴它們：
- 隨機節點相位使嵌入孤子的能量改變 −134（ne = 16、24、32 都是這個量級）；
- 平滑相位場（振幅 1.5 rad）使能量下降 0.93、0.20、0.066（ne = 16、24、32）；
- 牛頓法只在非對角座標（Cayley 圖）中走，不調整相位；相位沿路徑累積（和樂）。沿長路徑到達的兩個態，能量比較可以差到 0.84（ne = 16）。

## 2. 兩種規範不變的離散化

本輪做了兩種，互相核對：
- **投影子內插**（`disc="proj"`）：內插 P_a = Z_a Z_a†，公式見 2.1。完全不依賴規範的選擇，但每次 Hessian–向量乘積比舊版慢 25 倍（ne = 16：2.2 s 對 0.09 s），ne = 32 的延拓做不動。只用來核對正規形係數。
- **元素內對齊**（`disc="align"`，主要結果都用它）：仍然內插 U，但在每個求積點，先把該元素每個節點的各列相位對齊到元素中心節點（⟨Z_a(中心), Z_a(n)⟩ 取為正實數），再內插。改變節點相位時，每個元素的每一列只多出一個共同相位；每一項能量都與這個相位無關，所以離散能量**逐位元**不變。速度與舊版相同。對齊只在相鄰節點的列幾乎正交時失效，那表示場在元素尺度上沒有解析，本輪沒有遇到。

### 2.1 投影子內插

節點上仍存 U，也仍用同一個 Cayley 圖與 R 對稱切片；改變的只是能量怎麼算（`FlagModel(disc="proj")`）。在每個節點取投影子 P_a = Z_a Z_a†，在求積點內插 P_a（而不是 U）。節點相位在 P_a 中完全消失，所以離散能量只是節點旗的函數。

軸對稱時 U = R_L(φ)Û，P_a = R_L P̂_a R_L†；每一項都是跡，R_L 的共軛不影響結果。記 D_ρ、D_z 為內插 P̂_a 的導數，D_φ P̂ = (i/ρ)[L, P̂]：

```
|ω_i^{ab}|²      = −½ Tr(D_iP_a D_iP_b)                            (a ≠ b)
F^{(a)}_{ij}     = −i Tr(P_a [D_iP_a, D_jP_a])
|C^{ac}_{ij}|²   = ‖ P_a (D_iP_b P_b D_jP_c − D_jP_b P_b D_iP_c) P_c ‖²
1 − |Z_aa|²      = Σ_{c≠a} Σ_d |(P_a)_cd|²
```

對精確的投影子，這四式就是舊離散化的公式（第三式可由 P_a D_iP_b P_b = Z_a ω_i^{ab} Z_b† 驗證）。

**位能項為什麼用平方和。** 最直接的寫法 1 − (P_a)_aa 對內插的 P 是線性的，等於「集中質量」：它在壓縮網格外緣被強烈拉伸的元素上不是正定的。第一版就是這樣寫的，結果出現兩個假象：
- 區塊內在遠場（⟨r⟩ ≈ 29）有一組三重簡併的假模，本徵值 0.56，低於連續譜 2；
- 法向區塊在 κ₃ = 2 仍有負特徵值，正規形程式的前提檢查因此失敗。
改用平方和 Σ_{c≠a}Σ_d |(P_a)_cd|²（對精確投影子恆等於 1 − |Z_aa|²）以後，它逐點非負，靠近真空時的主部是一致質量 |x|²，兩個假象都消失。

**Hopf 荷。** Q_h 仍由內插的提升 U 計算，所以仍然看得到節點相位。每次計算前先把各列相位調到最平滑的規範（`flag_gauge.py`：沿梳狀生成樹取平行規範，再以牛頓法極小化 Σ|w|(1 − cos)，即離散 Coulomb 規範）。這一步不改變旗，也不改變能量。核對：嵌入孤子加上隨機節點相位後 Q_h 從 −0.99936 變成 +0.026，平滑後回到 −0.99933；R2 §3.6(d) 的終點 T 從 −0.99396 回到 −0.99930。

粗步長（0.04）下 D₂ 在 0.76 → 0.72 之間由 4.2 跳到 8.1。細掃（ne = 16 步長 0.005，ne = 24 步長 0.01）顯示：

- (D₀ − D₂)² 對 κ₃ 是直線，也就是 D₀ − D₂ ∝ √(κ₃ − κ₃_p)：這是超臨界的叉形分岔。外推 κ₃_p = 0.7237（ne = 16）、0.722（ne = 24）。能量平滑通過。
- κ₃ > κ₃_p：兩支互為鏡像的非對稱分支 S 與 g(S)，g = P₀₂ 交換第 0、2 條線。兩者能量**完全相同**：從對稱態往上掃時，牛頓法走上 g(S)，D₀ − D₂ 變號（κ₃ = 0.7612：−7.166 對 +7.166），ΔE 相同到全部位數（−2.34899）。
- κ₃ < κ₃_p：一支 0 ↔ 2 對稱的 F₂ 分支（D₀ = D₂）。
- 在 κ₃ = 0.7262（剛好在 κ₃_p 之上），對稱態在 R 偶扇區有一個負特徵值：它在那裡是鞍點，正是叉形分岔應有的樣子。
- 往下與往上掃描走的是同一組態（或它的鏡像），**沒有遲滯**。

所以 R2 §3.6(d) 在舊離散化下看到的「跳躍與遲滯」不是物理：粗步長跨過了平方根型的陡峭段，舊離散化的節點相位效應又讓兩支鏡像分支的能量不再相等，看起來像兩個不同的分支。
