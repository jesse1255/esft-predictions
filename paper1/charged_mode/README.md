# Paper 1 研究續篇：放開方向場的兩個切向分量

**2026-09-24。** 本輪接續 2026-09-08 的研究報告〈補入截面電流的磁場，並檢查模式能否重新平衡〉。那份報告最後找到一個非零的角向一階導數，所以結論是：只用一條徑向函數 h(r) 描述的構型，還不是方向場方程的駐定解。本輪從頭寫了一套獨立程式，先重現報告的 h(r) 結果，再在子午截面上放開方向場的兩個切向分量（緯度與相位），並在每一步重新求解電勢、方位磁勢與子午磁勢。

> *English summary.* An independent axisymmetric finite-element code reproduces the
> 2026-09-08 restricted-profile results for the charged, gauged Hopfion
> (e = 0.3, f = g = μ = 1, N = 1) to within that note's own discretisation error.
> The full two-dimensional relaxation of the direction field together with all
> electromagnetic fields then yields a converged stationary state (grid sequence
> ne = 32–96, O(h⁴) convergence).
> Relative to the h(r) profile it lowers the energy by 0.4994 (0.16 %) and changes the
> charge rms radius by −0.064 %. The charge distribution becomes 5.2 % more oblate,
> and the magnetic moment rises by 0.91 %. All shape probes of the earlier note vanish
> at the new state. Model inputs are not derived. The configuration is classical, and
> none of these numbers is an electron property. See the last section for the
> dimensionless gap.

## 1. 模型與化約

作用量與 2026-09-08 報告相同，取 ℏ = c = 1、f = g = μ = 1、e = 0.3、固定 N = Q/e = 1：

```
E_N = ∫ d³x [ f²/2 |Dn|² + 1/(4g²) Σ_ij (n·D_i n × D_j n)² + f²μ²(1+n₃) + ½|∇×A|² ]
      + N² / (2 I_eff),
D_i n = ∂_i n + e A_i (e₃ × n),
I_eff = min_β ∫ [ β² K + |∇β|²/e² ],  β → 1,   K = f²(1−n₃²) + g⁻²|∇n₃|².
```

我先把報告寫出的 M_ij、w_i、K 與 J = −ew − e²MA 逐項由這個作用量重推一次，全部一致。固定荷項 N²/(2I_eff) 在 Gauss 定律成立時是精確的：A₀ = ω(1−β)/e，ω = N/I_eff。

軸對稱時令 n = R₃(mφ) u(ρ,z)，其中 u ∈ S²、m = 1，A = A_ρ ρ̂ + A_z ẑ + A_φ φ̂。令 T = e₃×u、Φ = m/ρ + eA_φ，則

```
|Dn|²       = |∂_ρu + eA_ρT|² + |∂_zu + eA_zT|² + Φ²|T|²
Σ_ij F_ij²  = 2 [ F_ρz² + Φ² |∇u₃|² ],   F_ρz = u·(∂_ρu×∂_zu) + e(A_ρ∂_zu₃ − A_z∂_ρu₃)
```

所以方位電流 J_φ = −eΦK。u 在子午半平面上是完整的單位向量場，緯度與相位都是自由度。h(r) 族只是其中一條曲線：

`u₁+iu₂ = 2 sin h sinθ (cos h − i sin h cosθ)`，`u₃ = 2 sin²h sin²θ − 1`。

**規範處理。** 放開 u 的相位以後，(u 的相位, A 的梯度部分) 之間有精確的規範冗餘。本輪在能量中加入 κ/2 (∇·A)²（κ = 1）。任何軸對稱構型都能在不改變能量的前提下規範變換到 ∇·A = 0，所以這一項不改變最小值，只消除零模。這與報告反對「人工 Coulomb 懲罰項」並不矛盾：報告的情形是 n 固定，相位不能動，此時梯度部分代表真實的相位鬆弛，不能刪。本輪重算 h(r) 族時也照這個原則處理：u 固定，κ 只取 10⁻⁸ 作外域正則化。第 4 節有這一點的數值核對。

**離散。** 採用張量積二階 Lagrange 元素（Q2）與 3×3 Gauss 積分。網格經過壓縮座標 ρ = a tan(πξ/2)、z = a tan(πη/2)（a = 3），最外圈節點就在空間無窮遠，β = 1、A = 0、u = −e₃ 都在那裡精確施加，不需要 Robin 項。另外有兩處處理：
- 以 |T|² = u₁²+u₂² 代替 1−u₃²，讓軸上的 O(ρ²) 行為正確；
- 位能寫成 f²μ²|u+e₃|²/2，使節點之間的內插值仍有下界。這兩個改寫對單位向量完全等價。

主計算只存 z ≥ 0，並施加反射對稱 (z→−z, u₂→−u₂, A_ρ→−A_ρ)。第 5 節有不施加此對稱的全平面檢查。

**求解。** 完整放鬆用阻尼牛頓法：u 在每個節點用兩個切向座標，A 的三個分量照常。每一步都重新求解 β，接受或拒絕試探步一律看精確的 E_N。收斂判準是牛頓遞減量低於能量捨入水準；各網格最後的 |g/√H|max 約 10⁻¹⁰。

## 3. 放開兩個切向分量之後

從 h(r) 族的最佳點出發，u（緯度與相位）與 A_ρ、A_z、A_φ 聯合放鬆，β 每步重解：

能量分項（ne = 96，h → 完整）：
- 二階導數項 98.254 → 98.129；四階導數項 169.174 → 168.410；位能 27.885 → 27.826。
- 磁場能 12.739 → 13.189。其中子午磁勢產生的 B_φ 6.459 → 6.724，方位磁勢產生的極向場 6.281 → 6.465。
- 固定荷項 0.00671 → 0.00666。

渦環幾何（z = 0 平面上 u₃ = +1 的核心環，相位繞著它轉一圈）：
- 核心半徑 0.920 → 0.917；
- u₃ = 0 的內外半徑 0.446–1.547 → 0.443–1.561；
- 管子半高 0.784 → 0.780。

可以看出，放鬆主要是讓截面稍微橫向變寬、縱向變薄，並重新分配相位梯度：四階項降低、磁場能增加。

**解讀。** 報告指出的角向非駐定是真實的，但放開兩個切向分量後，能量只再降 0.16%。電荷半徑幾乎不動（−0.064%），真正有感的變化是形狀（四極矩）與磁矩。換句話說，h(r) 族已經相當接近這個模型的軸對稱最低點；要談準確的形狀與磁矩，就必須放開兩個切向分量。

## 5. 穩定性與反射對稱

**反射對稱扇區（主計算的扇區，`check_hessian_ne48.json`）。** 在最終解上用中心差分組出離散 Hessian，以一致質量矩陣的對角元正規化，最低 8 個特徵值全部為正（3.1×10⁻⁶ 起）。這 8 個模 100% 位於 A 場、而且全在 r > 6，屬於無質量 Maxwell 場在無限外域的連續譜，所以數值很小。固定 A、只看方向場部分時，最低特徵值是 0.0705，明確為正。Hessian 省略了固定荷項的非局部部分，那部分是半正定的，只會讓特徵值變大，所以「局部最小」的結論不受影響。

**不施加反射對稱（全平面，`check_fulldomain_ne32.json`、`..._ne48.json`）。**
- 把解鏡射到整個子午平面後，梯度仍為零（2.5×10⁻⁶，與半平面相同量級），能量相同（差 10⁻¹⁰）。
- 最低的兩個模是預期中的對稱模：
  - z 向平移：和 ∂_z u 的重疊 0.94。數值是 −2.1×10⁻⁴（ne = 32）與 −1.2×10⁻⁴（ne = 48），隨加密變小。原因是能量由下往上收斂，孤子往網格較粗處移動會降低離散能量。
  - 整體相位旋轉：這是精確對稱，數值為 −2×10⁻⁵ 到 −5×10⁻⁵，與外域連續譜同一量級。
- 其餘特徵值都為正。
- 給一個 z 反對稱擾動（能量升到 307.602）再放鬆，回到同一能量（差 10⁻¹⁰），能量質心 z ≈ 10⁻⁵。

牛頓法收斂到的是駐定點，所以這一步不能單獨證明沿平移方向穩定。但平移在連續極限是精確對稱，上述負值是網格效應。

非軸對稱擾動（φ 方向的角動量 ≠ 0）本輪沒有做。

## 6. 還沒做、以及這些數字離電子有多遠

仍未完成的項目：非軸對稱擾動、量子化（自旋、電荷量子化）、作用量與 e、μ、f、g 的來源。本輪的解是古典的軸對稱駐定點，只在軸對稱扇區內檢查過穩定性（第 5 節）。

把模型單位換成電子時，不需要任何額外假設就能讀出的無因次量：

- **尺寸相對於康普頓波長。** 在 ℏ = c = 1 下，M·r_rms = 307.56 × 1.5956 ≈ 491。若令 M = m_e，則 r_rms ≈ 491 × 386.16 fm ≈ 1.9×10⁵ fm，約 3.6 個 Bohr 半徑，比實驗對電子尺寸的上限大八個數量級以上。這類作用量在 μ/(fg) 與 e 固定時，M·R 正比於 1/g²（g 是四階項的無因次耦合）；要降到 10⁻⁵ 以下，需要 g² ~ 10⁷–10⁸，此時古典孤子近似不再成立。
- **磁矩的來源。** 磁矩主要來自方位繞迴 m = 1 造成的靜態電流 J_φ = −eΦK，與轉動無關：N = 0 時構型與能量幾乎不變。若把它硬寫成 g 因子 2Mμ/(QJ)，取 J = ½ 會得到約 6×10⁴，與 2 相距甚遠。

所以本輪的結果應該讀成「這個古典模型的電磁結構已經算對、算準」，而不是「這個模型已經重現電子」。要讓任何一個數字和電子實驗值比較，至少要先完成量子化，並處理上面的尺度問題。
