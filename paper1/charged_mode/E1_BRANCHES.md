## 1. E1：非軸對稱二階變分

### 1.1 推導

背景是上一輪的軸對稱解：n = R₃(mφ) u(ρ, z)，A = A_φ(ρ, z) φ̂（另有 A_ρ、A_z 的規範自由度）。擾動允許依賴 φ。改用**共轉標架**：

```
n = R₃(mφ) v(ρ, φ, z),   A = A_ρ ρ̂ + A_z ẑ + A_φ φ̂,
T = e₃ × v,   Φ = m/ρ + e A_φ,
p_ρ = ∂_ρ v,  p_z = ∂_z v,  q = ρ⁻¹ ∂_φ v.
```

共變導數與場強：

```
D_ρ v = p_ρ + e A_ρ T,   D_z v = p_z + e A_z T,   D_φ v = q + Φ T,
F_ρz = v·(p_ρ × p_z) + e (A_ρ p_z3 − A_z p_ρ3),
F_ρφ = v·(p_ρ × q)  − Φ p_ρ3 + e A_ρ q₃,
F_zφ = v·(p_z × q)  − Φ p_z3 + e A_z q₃,
B_ρ = ρ⁻¹∂_φA_z − ∂_zA_φ,   B_φ = ∂_zA_ρ − ∂_ρA_z,   B_z = ∂_ρA_φ + A_φ/ρ − ρ⁻¹∂_φA_ρ,
∇·A = ∂_ρA_ρ + A_ρ/ρ + ρ⁻¹∂_φA_φ + ∂_zA_z.
```

F 的化約和上一輪一樣，用了單位向量恆等式。∂_φ = 0 時，這組式子逐項回到軸對稱的離散能量，所以軸對稱解在這個更大的空間裡仍是駐定點。數值上，背景處的梯度是 2.5×10⁻⁶（k = 0）與 2×10⁻¹⁶（k = 1）。

**扇區分解。** 背景與 φ 無關，所以二階變分對 k 嚴格分塊。在第 k 扇區取

```
v = normalise(u₀ + Σ_{i=1,2} [c_i cos kφ + s_i sin kφ] e_i),
A = A₀ + c_A cos kφ + s_A sin kφ,
```

每個節點有 10 個實係數。e₁、e₂ 是 u₀ 的切標架。φ 積分用 M = 2k + 3 個等距點；二次型是次數 ≤ 2k 的三角多項式，所以這個積分是精確的。

**軸上的正則性**（實驗室系光滑）：

| k | 條件 |
|---|---|
| 0 | δv = 0，δA_ρ = δA_φ = 0，δA_z 自由 |
| 1 | δv₁ + iδv₂ ∝ e^{−iφ}（軸上標架 e₁ = −x̂、e₂ = ŷ 時 s₁ = −c₂、s₂ = c₁）；δA_ρ + iδA_φ ∝ e^{−iφ}；δA_z = 0 |
| ≥ 2 | 所有擾動在軸上為零 |

**規範場。** 加上庫侖規範項 ½κ(∇·A)²，使 H_AA 正定（純規範方向 A → A + ∇χ、v → e^{eχ}v 因此被移除；相位本身自由，這一項合法）。對每個物質擾動都讓 A 重新鬆弛，也就是看 Schur 補

```
S = H_mm − H_mA H_AA⁻¹ H_Am,     S x = λ M_mm x,
```

M_mm 是物質擾動的一致 L² 質量矩陣。在這個度規下，自由真空的連續譜從 λ = μ² 開始（固定電荷項再把它下移 ω²，見 1.2）。求解時用 (S − σM)⁻¹ = [(H − σ diag(M_mm, 0))⁻¹]_mm，以 PARDISO 分解做 shift-invert。

**固定電荷項。** N²/(2I_eff[n]) 的二階變分可分成兩部分。局部部分固定 β，為 −(ω²/2)∫β² δ²K。其餘部分包含 β 的響應與 (δI)² 項，是半正定的；β 的響應項非負，因為 I_eff 是對 β 的極小。程式只放了局部部分，所以**算出的 Hessian ≤ 真 Hessian**。「算出來沒有負模」可以直接推到「真的沒有負模」。

Hessian 由 JAX 的精確 Hessian–向量積以圖著色組出（對稱性誤差 ~10⁻⁸）。程式：`nonaxisym.py`、`run_nonaxisym.py`。

## 2. 分支 2：量子化後的靜態電流磁矩

### 2.1 集體座標與 FR 條件

m = 1 的軸對稱 Hopf 孤子，繞對稱軸轉 β 等於同位轉動 −β。所以剛性轉動與同位轉動的軌道就是 SO(3) 本身，而體座標自旋投影被 U(1) 電荷鎖住：K₃ = −mN。轉子哈密頓量為

```
H = E_N + [J(J+1) − K₃²] / (2 V₁₁),
```

E_N 已經含同位轉動能 N²/(2I_eff)。V₁₁ 是繞垂直軸的慣量：

```
V₁₁ = ∫ [ f²|δv|² + g⁻² Σ_i (v·(δv × D_i v))² + |δA|² ] d³x,
δv = −[ρ sinφ ∂_z v − z sinφ ∂_ρ v − (z cosφ/ρ) T],   δA = −𝒟A + x̂ × A,  𝒟 = y∂_z − z∂_y.
```

與同位轉動的交叉項在 φ 平均後為零；Coulomb 電場只做剛性轉動。核對：用同一套程式算 V₃₃ 的裸值得 112.497，直接積分 ∫K 得 112.501。

**統計。** 2π 空間轉動與 2π 同位轉動是同一條迴路。
- 若按玻色子量子化，J 與 N 都是整數。
- 若按費米子量子化，J 與 N 都是半整數，最小電荷是 **Q = e/2**。文獻（Krusch & Speight 2006）指出，奇 Hopf 荷的這條迴路不可縮，可以按費米子量子化；本輪沒有重推這一點。

所以若要 J = ½，就必須 N = ½。若再要求 Q = √(4πα)，則 e ≈ 0.606（程式用 e = 0.6）。

## 3. 分支 1：A₂ 旗流形 Hopf 孤子

### 3.1 模型與嵌入解

序參量是 U = [Z₁ Z₂ Z₃] ∈ U(3)，模掉右乘的對角相位，也就是 F₂ = U(3)/U(1)³（實維 6）。π₂(F₂) = ℤ²，π₃(F₂) = π₃(SU(3)) = ℤ。能量取

```
E = ∫ d³x [ Σ_{a<b} r_ab |ω_i^{ab}|²
            + (κ/2)  Σ_{i<j} Σ_a (F^{(a)}_{ij})²
            + (κ₃/2) Σ_{i<j} Σ_{a≠c} |C^{ac}_{ij}|²
            + m² Σ_a (1 − |Z_aa|²) ],
ω = U†∂U,   F^{(a)}_{ij} = 2 Im Σ_{b≠a} ω̄_i^{ba} ω_j^{ba} = −i Tr P_a[∂_iP_a, ∂_jP_a],
C^{ac}_{ij} = ω_i^{ab} ω_j^{bc} − ω_j^{ab} ω_i^{bc}     ({a, b, c} = {1, 2, 3}).
```

F^{(a)} 是第 a 個 CP² 因子的 Kähler 形式拉回。[ω_i^off, ω_j^off] 的對角部分正好是 −iF^{(a)}_{ij}，非對角部分是 C^{ac}_{ij}。因此：

- **κ₃ = 0** 就是審查報告 §4.2 提議的最小模型 **M2**；
- **κ₃ = κ** 時兩個四階項合起來是 (κ/2)Σ_{i<j}‖[ω_i^off, ω_j^off]‖²，記為 **M2′**。

耦合取 κ = 2、m² = 1、r₁₂ = 2、r₁₃ = r₂₃ = 2λ；λ = 1 是 S₃ 對稱點。

**嵌入解。** 令 Z₃ = e₃，(Z₁, Z₂) 只在 ℂ² 內轉動。這時能量逐項等於 f = g = μ = 1 的 Faddeev–Skyrme 模型（r = 2f²、κ = 2/g²、m² = f²μ²）。C 在任何嵌入構型上恆為零，所以嵌入解與 λ、κ₃ 都無關：E_emb = 321.4388（ne = 16）、321.5897（ne = 24）。直接積分 Q = (1/24π²)∫Tr ω̃³ 得 −0.99936、−0.99988。

**軸對稱。** U = R_L(φ)Û(ρ, z)，L = diag(0, 1, l₃)。嵌入的 m = 1 解取 (l₁, l₂) = (0, 1)。l₃ 標記法向擾動（把 Z₃ 轉進 Z₁、Z₂ 平面）的角動量扇區。軸上只有 l_a = l_b 的 x_ab 可以不為零。

程式：`flag_axisym.py`（模型、精確 HVP、LDLᵀ 慣性、束縛）、`run_flag.py`、`run_flag_k3.py`、`run_flag_branch.py`、`flag_path.py`。

### 3.2 法向 Hessian 的線性閾值

- λ_c = −θ_min，θ 為束 H_a v = θ H₁ v 的最小特徵值；
- κ₃* 用 LDLᵀ 慣性指數二分。

### 3.3 M2 沒有正的拓樸下界

把 ω 分成對角的聯絡 a 與非對角的 β，由 Maurer–Cartan 方程 da_a = −(β∧β)_{aa} 得

```

```

- 第一項是三個 U(1) 聯絡的 Chern–Simons 項，da_a ∝ F^{(a)}。和 Faddeev–Skyrme 一樣，Vakulenko–Kapitanski 型估計給出 |Q_CS| ≤ C E^{4/3}。
- 第二項是三循環項，|∫Tr β³| ≤ ‖β‖₂ ‖(β∧β)_off‖₂ ≤ C √(E₂ · E_C)。它**只受 κ₃ 項控制**。

**反例（數學證明）。** 取實旗 U ∈ SO(3) ⊂ SU(3)。這時 ω 是實反對稱矩陣，所以所有 F^{(a)} ≡ 0，M2 的四階項恆為零。SO(3) ⊂ SU(3)（自旋 1 表示）的 Dynkin 指標是 4，所以這類構型的 Hopf 度數是 4k，而且可以不為零。對 Q = 4 的實構型做縮放 x → x/R：E(R) = R E₂ + R³ E_pot → 0。**M2 在 Q = 4 扇區的能量下確界是 0，沒有極小（能量非負，所以精確說法是「正下界不成立」）。** M2′（κ₃ > 0）把三循環項也納入控制，上式給出 |Q| ≤ C₁E^{4/3} + C₂E，下界恢復。這只是證明草稿，常數與細節待補。

### 3.4 M2′：S₃ 點上的嵌入孤子是穩定的

在 M2′（κ₃ = κ = 2）、λ = 1、ne = 24 時，六個扇區 l₃ = −2…3 的法向 Hessian 都沒有負特徵值。最低的 L² 正規化特徵值是 2.00005（l₃ = 0、1）到 2.0002（l₃ = −2），也就是法向連續譜的起點 2m²。所以 S₃ 點沒有法向束縛模。線性閾值很遠：λ_c = 0.0505（l₃ = 0、1）、0.0160（l₃ = −1、2）、0.0069（l₃ = −2）。ne = 16 → 24 的變化小於 8%。

**λ 方向的一級共存。** 在同一條耦合線 r = (2, 2λ, 2λ) 上：
- 12 區塊的嵌入孤子能量與 λ 無關（E₁₂ = 321.59）；
- 13、23 區塊的嵌入孤子是剛度 r = 2λ 的 Faddeev–Skyrme 孤子，能量 E₁₃ = E₂₃ 隨 λ 單調遞增（dE/dr = ∫|ω|² > 0）。

三者在 λ = 1 相等，這是 S₃ 對稱強迫的能量交叉：λ > 1 時 12 最低，λ < 1 時 13、23 最低。12 分支從 λ = 1 一路局部穩定到 λ_c ≈ 0.05，所以共存點（λ = 1）與它的線性閾值（λ ≈ 0.05）相距很遠，中間是寬的遲滯區。

這是一個乾淨的受控例子：**一級共存出現在線性閾值之前**。但共存點的位置由對稱性決定，不是動力學預言。三個簡併分支的質量比 E₁₃/E₁₂ 是 λ 的連續函數，也就是參數，不是預言。這正是 §4.2 對「三代」的預先警告。

- 牛頓法，κ₃ = 0.6 與 0.88；
- 小步長下降，κ₃ = 0.6 與 0.88。

四次最後都在網格尺度流失 Hopf 荷，**沒有找到收斂的 F₂ 極小**（`data/flag_newton_collapse_ne16.json`、`data/flag_path_ne16_l0_lam1_k3{0.6,0.88}.json`）。κ₃ = 0.88 的下降路徑前 10 步幾乎停住（|∇E| 降到 7×10⁻³，D ≈ 0.35–0.53，ΔE ≈ −0.12）。之後梯度重新變大，R_E 增大，Q 從對角部分流失。

κ₃ = 0.88 只比閾值低 4%。若分岔是超臨界的，旁邊應該有一個振幅很小的 F₂ 解。前 10 步的近停滯可能就是它，但因為網格讓電荷漏掉，我們無法確認它是極小還是鞍點。**判定：未排除，需要 ne ≥ 32 重做，並在牛頓法之外同時追蹤 Q。**

### 3.5 對 7 月 C/E/H 的含意

7 月的腳本仍未核對，以下只是受控模型給出的、可以直接拿去檢查 7 月計算的教訓：

1. **四階項不完整、或網格太粗時，「相」可能只是網格撐住的。** 在 M2 中，嵌入態在 S₃ 點不穩定，而且 Q = 4 扇區根本沒有下界。在 ne = 16 上，即使四階項完整，Q = 1 的電荷也會沿失穩方向從網格漏掉。在這種情況下，固定網格上量到的任何「共存點」或「近簡併」都會隨加密移動或消失。7 月撤回的「格點 Skyrme 項未收斂」與此同類。**檢查方法：**沿鬆弛路徑計算 Hopf 度數及其三循環部分；確認四階項包含完整的非對角交換子；並做網格加密。
2. **四階項完整時，一級共存是乾淨的，但位置由對稱性決定。** M2′ 的共存點在 λ = 1，12 分支的線性閾值在 λ ≈ 0.05，兩者分得很開。7 月固定背景的數字是 β_co = 0.04197、β_lin = 0.04258，只差 1.4%；反作用外推後 β_co ≈ 0.0433，已經超過 β_lin。在一個良定的模型裡，被取代的相在共存點之前就已經線性不穩定，這是矛盾的。受控模型把正確的先後順序明確呈現出來，也讓 §4.5 提出的疑點更具體。
3. **遇到不穩定時，先確認有沒有下界。** M2 的失穩不是發現了新相，而是作用量有缺陷。任何宣稱「新相勝出」的計算，都應該先說明該相所在的拓樸扇區有能量下界。

**對量子化。**
- 剛體轉子忽略了轉動造成的形變。轉動能只佔 10⁻⁵ 以下，這一點在 g ~ 1 時無害，但在 g ≳ 10 的區域會變重要。
- FR 條件取自文獻。若 Hopf 荷 1 的迴路其實可縮，J = ½ 就被禁止，費米子這一支整條消失。
- g_rot 只是對流估計，無散部分可能同量級，甚至改變符號。

**對旗流形。**
- 全部在軸對稱擬設內：每個 l₃ 是一個角動量扇區，但真正的極小可能同時用到多個扇區。
- F-1 的反例是 Q = 4。Q = 1 在 M2 中是否沒有下界，沒有證明；ne = 16 的荷流失在 κ₃ > 0 時也會發生，不能當證據。
- M2′ 的下界只是草稿。若它其實不成立，F-4、F-5 仍是局部陳述，但「三個穩定分支」的圖像就要打折。（2026-09-25：已證明並算出常數，Q = 1 時 E ≥ 56.5，見 R2 §3.4。）
- κ₃ 轉變的判定受限於 ne = 16。牛頓法可能跨過淺的局部極小；小步長下降又可能在網格尺度被「拉走」。兩者都不是證明。（2026-09-25：「拉走」的機制已找到，是被格點抬成負值的零模；在 R 對稱切片中重做後，轉變在局部是連續的，見 R2 §3.5–3.6。）
- **（2026-09-25 新增）離散能量依賴節點上的對角相位。** 連續極限中這些相位是規範；在網格上，平滑的相位場（振幅 1.5 rad）可使能量下降 0.93、0.20、0.066（ne = 16、24、32，∝ ne⁻⁴）。牛頓法只在非對角座標中走，相位只會沿路徑累積。所以沿長路徑到達的兩個態，能量比較在 ne = 16 可以差到 0.9；要比較，須先把相位也鬆弛掉，或改用規範不變的離散化（R2 §3.6(d)）。κ₃* 附近的小振幅結果不受影響（效應 ≤ 10⁻⁴）。
- 7 月的 C/E/H 在這裡沒有被重現，也沒有被否定。第 3.5 節只是把受控模型的教訓轉成可執行的檢查。
