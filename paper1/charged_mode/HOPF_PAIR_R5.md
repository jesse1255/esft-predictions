# 第五輪：兩個「太極漩渦」的結合與排斥

**2026-09-26。** 使用者要求：從太極／兩儀／四象的結構出發，把**疊加、消減、共振、邊緣的不穩定、容差**全部放進計算，「不管好壞都能檢驗」。本輪在一個寫得出作用量的受控模型裡，把這五件事逐一算出來。

**摘要。**
- **模型**：兩分量場（四象層），只有三個參數 f = g = μ = 1，沒有拿任何量測值去調。
- **疊加與消減 → 吸引與排斥**：兩個漩渦的交互作用 E_int ≈ −C·e^{−μd}/d²·cos(α − α₁)，C ≈ 1765。只改變相對相位 α，就在吸引與排斥之間連續切換；在 d ≥ 3.5，完整鬆弛後的結果與這條定律相差 0.4–3%。
- **結合**：吸引通道的位能曲線一路通到束縛態。共軸的「分子」A₁,₂（結合能 39.1，占 6.1%，有確定的鍵長）；融合成繞兩圈的單環 A₂,₁（結合能 132.2，占 20.6%，是電荷 2 的基態）。
- **共振**：單一漩渦沒有束縛的內部振動；分開的一對有長壽命的相對相位擺動 ω(d)；結合的一對，其振動在連續譜之上，是會輻射衰變的共振態。
- **邊緣的不穩定**：排斥相位不穩定，小擾動以 e^{γt} 放大，γ(d) = √(2B₁/I₁)（d = 4 時 0.19，d = 8 時 0.013）；參數的不確定也會被距離放大：δ ln B₁ = (1.23 − μd)·δμ/μ。
- **容差**：網格 ≤ 0.3%；μ 變動 ±10% 時，E₁ 變 ∓1.8%，C 變 −12%／+13%，A₂,₁ 結合能變 −2.3%（μ = 0.9）／+2.2%（μ = 1.1），A₁,₂ 結合能幾乎不變。
- **限制**：只算了共軸、古典、不帶電的情形。這是核力型的邏輯（短程、依賴相對取向），不是原子或化學鍵。

## 0. 模型：四象層的最小場

場是兩個複數分量 z = (z₁, z₂)，|z| = 1（四元數／自旋 ½ 的層次，即上一輪說的「四象」）。可觀測的是單位向量 n = z†σz，也就是把整體相位（兩儀的 S¹）除掉之後剩下的 S²。能量（`hopfion_axisym.Model`，e = 0，規範場退耦）：

```
E = ∫ d³x [ f²/2 |∇n|²  +  1/(4g²) Σ_ij (n·∂_i n × ∂_j n)²  +  f² μ² (1 + n₃) ]
         疊加（線性波動）    消減／飽和（四階，穩定孤子）        質量（場量子的共振頻率 μ）
```

取 f = g = μ = 1，只有這三個參數，而且**本輪沒有拿任何量測值去調它們**。

- 一個「太極漩渦」＝ Hopf 孤子：n 在一個環（核心，n₃ = +1）周圍扭一圈，Hopf 荷 Q = 1。軸對稱：n = R₃(mφ)u(ρ, z)，m = 1。
- 兩個漩渦的**疊加**用複振幅做：W = (u₁ + iu₂)/(1 − u₃)（真空 W = 0，核心 W = ∞），
  W = W_A(z − d/2) + e^{iα} W_B(z + d/2)。
  α 是兩個漩渦的**相對相位**：α 使兩者在中間區域同相就是「疊加」，反相就是「消減」。
- 兩個漩渦放在同一條軸上（共軸），間距 d。側邊並排需要三維計算，本輪沒有做（§8）。

**得到的定律（d ≥ 2.5）：**

  **E_int(d, α) ≈ −C · e^{−μd} / d² · cos(α − α₁(d))，C ≈ 1740–1790**

- **疊加 → 吸引，消減 → 排斥。** 同一對漩渦，只改變相對相位，交互作用就在吸引與排斥之間連續變換；最吸引與最排斥的大小相等、符號相反，平均值 c₀ 趨於 0。這正是兩個波在重疊區的干涉。
- **最吸引的相位不是 0，而是 α₁ ≈ 66°–92°**，隨 d 緩慢改變。原因是 Hopf 孤子的相位沿 z 方向扭轉（這就是 Hopf 荷），兩個漩渦的尾巴在中間區域要「對齊」，需要一個相對轉角。
- **作用距離由場的質量決定**：e^{−μd}，與 Yukawa 1935 年用有質量的場解釋核力的邏輯相同；1/d² 表示尾巴是偶極型的。
- 距離短時（d ≲ 2）高階諧波變大，疊加式本身也變粗糙，要看 §3 的鬆弛結果。

**參數敏感度（μ = 0.9、1.0、1.1，24×32）：**

讀法：
- **d ≥ 3.5：疊加式就是答案。** 鬆弛只改變 B₁ 0.4–3%、α₁ 0.3° 以內。§2 的定律在這個範圍是鬆弛後的真實結果。
- **d ≤ 3：鬆弛讓吸引佔上風。** 相位依賴的幅度變小（d = 2：B₁ 由 67.6 降為 27.2），平均值 c₀ 變成負的：兩個漩渦在近距離會自己變形去配合對方，大部分相位都互相吸引，只剩一個較窄的排斥窗（α ≈ 240°–330°）。
- **吸引通道的位能曲線**（每個 d 取最吸引的相位）：−0.12（d = 6）、−0.46、−2.00、−4.19、−8.44、−15.75、−26.1、−37.0（d = 1.5），一路平滑地通到 §4 的束縛態 A₁,₂（−39.1，核心間距約 1.0）。這就是一個「分子」的位能曲線：長程由 e^{−μd}/d² 主導，短程到平衡鍵長。

方法：把漩渦 A 的兩個集體座標（核心重心 Z = ∫z(1+u₃)²/∫(1+u₃)² = d/2，以及同位轉角 Φ = arg∫w(u₁+iu₂) = 指定值）用拉格朗日乘子固定，其餘全部用牛頓法鬆弛（KKT 系統）。成對的組態在反射對稱的半平面中表示（對每個 α 都成立），參考能量是同樣約束下單獨一個漩渦（全平面）。每個點都檢查 Hopf 荷是否仍為 2；在 d = 1.5 的少數反相點，格點讓兩個漩渦「解開」成真空（Q → 0），這些點列為失敗、不計入。

第一版曾用「釘住一個網格點」的方式固定相位與位置，結果不可靠：在二維裡釘住一個點是弱約束（點的容量為零），場可以繞過它。這一版已刪除。

## 4. 結合：兩種束縛態（`q2`）

| 狀態 | 結構 | E | Q | 結合能 2E₁ − E | 比例 |
|---|---|---:|---:|---:|---:|
| A₁,₂ | 兩個環上下疊在一起（核心在 z ≈ ±0.51，環半徑 1.07） | 603.70 | −1.997 | 39.08 | 6.1% |
| A₂,₁ | 一個環、繞兩圈（m = 2，環半徑 1.36） | 510.58 | −1.998 | 132.20 | 20.6% |

（24×32、a = 4。）

- A₁,₂ 是**共軸的一對在吸引相位下放開、自己靠攏**後停下的狀態：從 d = 2 和 d = 3 出發都收斂到同一個能量（相差 2×10⁻¹³）。它有確定的「鍵長」，像一個分子。
- 在本模型中 A₂,₁ 比 A₁,₂ 低得多，是電荷 2 的基態（文獻上 Faddeev–Skyrme 模型 Q = 2 的最低態也是 A₂,₁；依記憶，未核對）。兩個漩渦若能不受共軸限制地重組，會結合得更緊。
- 所以同樣兩個漩渦，**結合的方式不只一種**：疊在一起（弱）或融成一個繞兩圈的環（強）。

## 5. 共振

- **單一漩渦**：沒有束縛的內部振動（§1）。
- **分開的一對**：相對相位像一個擺。在吸引相位附近，小幅擺動的頻率 ω(d) = √(2B₁(d)/I₁)（相對轉動的慣量是 I₁/2）。因為 ω < μ，它不會把能量輻射出去，是長壽命的低頻共振。見 §6 的表（同一個數，在排斥相位附近就是不穩定的成長率）。
- **結合的一對 A₁,₂**：在連續譜 μ² = 1 以下**沒有**任何振動模態。兩個漩渦「相對扭轉」與「相對伸縮」的 Rayleigh 商分別是 20.0 與 33.6，遠在連續譜之上：這些振動會很快把能量以場量子的形式輻射掉，是真正意義上的**共振態**（有寬度、會衰變），不是穩定的激發。

## 6. 邊緣的不穩定與放大

在排斥相位（α₁ + 180°）附近，E_int(α) 是極大，相對相位是不穩定的：一個小擾動 δα₀ 以 δα₀ e^{γt} 成長，γ(d) = √(2B₁(d)/I₁)；在吸引相位附近，同一個數就是擺動頻率 ω。

| d | B₁ | γ = ω | 1/γ（e 倍時間） |
|---:|---:|---:|---:|
| 2.5 | 22.95 | 0.641 | 1.6 |
| 3.0 | 9.611 | 0.415 | 2.4 |
| 4.0 | 2.046 | 0.191 | 5.2 |
| 5.0 | 0.4810 | 0.093 | 10.8 |
| 6.0 | 0.1220 | 0.047 | 21.4 |
| 8.0 | 0.00914 | 0.013 | 78.2 |

（時間單位是光走過 1 個長度單位的時間；核心環半徑約 0.93。）

兩種「放大」：
1. **時間上的放大**：在排斥相位，任何小的相位擾動都會被指數放大，系統自己轉向吸引相位。這就是你說的「邊緣的不穩定」：兩個波的邊緣（重疊區）在消減的配置下不穩定，擾動在那裡長大。放大率隨距離指數變小。
2. **空間上的放大**：交互作用強度對場的質量 μ 的敏感度隨距離增加：δ ln B₁ = (1.23 − μd) · δμ/μ。μ 若有 1% 的不確定，在 d = 6 就變成約 5% 的交互作用不確定。這就是**容差**：它是由模型自己的結構算出來的，不是事後拿來對數據的。

## 8. 這代表什麼、不代表什麼

**代表：** 一個只有三個參數、寫得出作用量的「兩分量場」，不需要任何額外假設，就同時產生了：
- 由相對相位決定的吸引與排斥（疊加與消減）；
- 有確定鍵長的結合（A₁,₂）與更緊的融合（A₂,₁）；
- 共振：長壽命的相位擺動與會輻射的束縛態振動；
- 邊緣的不穩定與它的放大率；
- 一套由模型本身給出的容差。

這些定律都是**算出來**的，不是擬合的；換一組 (f, g, μ)，它們按 §2 的標度改變。

**不代表：**
- 這不是原子。原子的結合與排斥來自電磁作用與電子的量子性質（Pauli 不相容）。這裡的漩渦很重（E₁ ≈ 321，場量子只有 1），交互作用是短程、依賴相對取向的；這更像**核力**的邏輯（Skyrme 模型中核子就是孤子，核力就是孤子之間這種依賴取向的交互作用），而不是化學鍵。
- 只算了共軸的排列；兩個漩渦並排或斜放需要三維計算。
- 都是古典計算；量子化之後，相對相位的擺動會變成離散的能階（相對同位旋態），那是下一步。
- 若給漩渦帶電（電荷 q = 0.3，如前幾輪的帶電模型），在點電荷近似下，長程 Coulomb 排斥 q²/(4πd) 在 d ≳ 10 超過短程吸引，形成一個高約 5×10⁻⁴、位於 d ≈ 12.6 的位壘：同號電荷的漩渦在遠處互斥、在近處仍然結合，邏輯上和原子核的「強作用對 Coulomb」一樣。這只是估計（忽略電荷分布與磁偶極作用），不是計算結果。
